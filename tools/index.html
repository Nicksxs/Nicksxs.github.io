在线开发与诊断工具箱

免费的浏览器端开发工具：Java 生产诊断、URL 与 Base64 编解码、JSON 格式化、时间戳转换、文本处理和大模型运行参数生成。所有数据都在本地处理。

所有数据均在本地浏览器中处理

Java 生产诊断

日志、线程、启动参数和内存预算
GC GC 日志分析器 分析暂停时间、Full GC、堆回收量和事件时间线。 TD Thread Dump 分析器 统计线程状态、聚类调用栈并识别死锁线索。 JV JVM 参数检查器 解释启动参数，检查内存配置、版本兼容和冲突项。 ST 异常堆栈整理器 提取根因、压缩框架噪声并生成可分享的 Markdown。 MB JVM 内存预算计算器 估算 Heap、线程栈、Direct Memory 与 Native 余量。

开发者常用工具

编解码、格式化、时间与文本处理
URL URL 编解码 编码或解码 URL、查询参数与中文路径。 JS JSON 格式化 校验、格式化和压缩 JSON，并精确定位语法错误。 TS 时间戳转换 在 Unix 秒、毫秒、本地时间和 ISO 8601 之间转换。 B64 Base64 编解码 正确处理中文的 UTF-8 Base64 编码与解码。 SHA 哈希计算器 使用浏览器 Web Crypto 计算 SHA-256、SHA-384 和 SHA-512。 TXT 文本整理工具 文本统计、去重、排序、去空行和大小写转换。

大模型本地推理

根据硬件与模型配置生成运行参数
LLM 大模型运行参数生成器 按显卡、显存、内存、模型尺寸、量化与上下文生成推理命令。

本地处理，减少等待

编解码、格式化、日志解析和参数估算均在当前浏览器完成。对于 HPROF、完整 JFR 等超大二进制文件，仍建议使用 Eclipse MAT、JDK Mission Control 等桌面工具。
